# Мэдээлэл технологийн сорилын систем

Төрийн албан хаагчийн мэдээлэл технологийн мэдлэг шалгах монгол хэлний вэб апп.
`PDF` файлаас гаргаж авсан асуултуудыг ашиглан хэрэглэгчид сорил бөглүүлж, дүнг хадгалдаг.

## Онцлог

- **Монгол хэлний интерфэйс** — бүх текст монголоор
- **Хэрэглэгчийн бүртгэл/нэвтрэлт** — bcrypt-ээр хашлагдсан нууц үг, cookie session
- **Хоёр бүлэг сорил**
  - I. Мэдээлэл технологийн онолын сорил
  - II. Word/Excel/PowerPoint дадлагын сорил
- **Асуулт болон хариултын хольсон дараалал** — санамсаргүй эрэмбэ бүр удаа
- **Хугацаа хэмжигч**, ахиц харуулах progress bar
- **Хариултын шүүлт** — зөв/буруу тэмдэглэлтэйгээр харах
- **Дүнгийн түүх** — өмнөх сорилуудын дүнг харах

## Ажиллуулах

```bash
npm install
npm start
```

Сервер `http://localhost:3000` дээр эхэлнэ.

### Демо хэрэглэгч

## Файлын бүтэц

```
├── server.js           Express API + auth
├── data/
│   └── questions.js    Сорилын асуултын сан (PDF-ээс)
├── public/
│   ├── index.html      Гол HTML
│   ├── app.js          SPA client (vanilla JS)
│   └── styles.css      Загвар
└── package.json
```

## API

| Эндпойнт | Метод | Тайлбар |
| -------- | ----- | ------- |
| `/api/register` | POST | Шинэ бүртгэл |
| `/api/login`    | POST | Нэвтрэх |
| `/api/logout`   | POST | Гарах |
| `/api/me`       | GET  | Одоогийн хэрэглэгч |
| `/api/results`  | POST | Дүн хадгалах |
| `/api/results`  | GET  | Миний дүнгийн түүх |
