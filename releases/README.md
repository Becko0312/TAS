## Суулгах заавар

1. Дээрх APK файл дээр дарж татаж авна.
2. Android утсандаа "Тодорхойгүй эх сурвалж" (Unknown sources / Install unknown apps)
   зөвшөөрлийг идэвхжүүлнэ.
3. Татсан APK-г нээж суулгана.
4. Демо хэрэглэгч: `demo` / `demo123` эсвэл шинэ бүртгэл үүсгэнэ.

> APK нь debug түлхүүрээр гарын үсэг зурагдсан тул Google Play Store дээр
> нийтлэх зорилготой биш, шууд суулгах (sideload) зориулагдсан.
